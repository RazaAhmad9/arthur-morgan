# Arthur Morgan — Cinematic landing page

Open `index.html` in any modern browser. No build tools or framework needed.

Files: `index.html`, `style.css`, `script.js`.

Features: cinematic intro, oversized display typography, animated atmospheric background, scroll reveals, mobile navigation, honors toggle, responsive layout and reduced-motion support.

**Images and fonts:** The hero character image is referenced from Rockstar's official Red Dead Redemption 2 site. Google Fonts and this image require an internet connection. If the image server becomes unavailable, the page falls back to a typography-led design. For reliable hosting, replace the image URL in `index.html` with an appropriately licensed, locally hosted image.
